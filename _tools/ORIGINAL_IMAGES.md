# 原本画像の更新ルール

- 原本は毎回「古プリ修正モード」ZIP内のPDFから取得する。
- PDFがないページのみ、ユーザーが明示許可した同ZIP内 `pages/` のJPEGをそのまま利用できる。2026-09-05に今回のv5について許可を取得した。
- サイトのbase/baseOff、過去のHTML、canvas、加工済みパックを生成元にしない。
- hide / keep / greenHide / numberPairs / 赤文字消去を画像へ焼き付けない。HTML側の表示処理で扱う。
- No.81/183のON/OFF別原本は、各々の対応が確認できる場合だけ使用する。片方を推測して作らない。
- 解像度・縦横比を変更しない。JPEGの再圧縮は禁止。PDFの単一全ページ画像を無加工抽出し、単純抽出できないPDFは処理を停止する。

## 安全な差分生成

`repair_base_from_zip.py` に最新サイト、修正モードZIP、レビュー済み修正計画、新規出力先を指定する。
計画には対象asset、ページキー、修正理由、現在画像SHA256、ZIP内原本パス・ページ・SHA256を必須とする。
PDFが存在するNo.にはJPEGへのフォールバックを許可しない。
生成後は `assets/original-image-provenance.json` に原本ZIP・原本画素・出力のハッシュと取得方法が記録される。

更新ツールは、変更されるbase/baseOff/tray画像について、この記録を照合してから書き込む。
記録のない旧パックやハッシュが一致しない加工済み画像は、書き込み前に停止する。
これは誤った旧画像の再投入を防ぐ整合性チェックであり、偽造された出典の真実性を自動証明するものではない。
原本そのものとの照合は必ず上記ZIP抽出工程で行う。

古いローカル生成スクリプトは今回使用停止にした。古いパックの画像をコピーするために再有効化しない。
