# 教材ライブラリ：色別の追加と操作案内 v16

GitHub最新版 0f8cf85895ce3e8ac6e3410f00cb722e959efe6e を基準に変更。
この更新は教材ライブラリの編集画面・表示処理のみ。写真対応は追加しない。

## 適用方法

CloudflareのWorker・D1・R2は設定済みのv15のまま使用できる。
SQL実行、Worker更新、契約や保存先の再設定は不要。

1. v16のZIPを解凍せず `_update_inbox` に1個だけ置く。
2. `更新パックを適用.bat` を実行。
3. GitHub DesktopでCommit → Push。
4. 公開サイトを再読み込みし、教材ライブラリの教材で「編集」を開く。

## まず試す操作

### オレンジ文字を追加

1. 「オレンジ文字を追加」を押す。
2. 出てきた欄に追加する語句を入力する。
3. 「PDFに配置する」を押すとPDFへ移動する。
4. 置きたい場所をタップすると、文字に応じた大きさで配置される。
   自分で広さを決めたい場合は、指やマウスで範囲を囲む。
5. 「下書きを保存」を押す。

### 緑マーカーを追加

1. 「緑マーカーを追加」を押すとPDFへ移動する。
2. 隠して覚えたい原文の範囲を、左上から右下へ囲む。
3. 「下書きを保存」を押す。
4. 「表示を試す」で緑をOFFにすると緑色で覆って隠れる。
   ONにすると原文が見える（淡い緑の印が付く）。

緑色の文字を入力したい場合は「ほかの色の文字を追加」→「緑文字を入力して追加」を使う。
緑マーカーと緑文字は別の編集項目で管理され、閲覧時は同じ緑の表示スイッチに連動する。

### 赤文字を隠す範囲を追加

1. 「赤文字を隠す範囲を追加」を押す。
2. 原本の赤文字を隠したい部分だけ囲む。
3. 「表示を試す」で赤をOFFにすると、その範囲が白く隠れる。ONで原文が見える。

これは手動の範囲指定。範囲内の黒文字なども一緒に隠れるため、対象の文字に沿って小さく囲む。
赤色の文字そのものを新しく入力する場合は「ほかの色の文字を追加」→「赤文字を入力して追加」。

### 直す・消す

- 「配置したものを直す」の「種類」でオレンジ・緑マーカー・赤の範囲・その他の文字を別々に一覧表示できる。
- PDF上の追加項目、または一覧の項目を選ぶ。
- 文字は入力を直して「選択した文字を更新」。
- 位置は「選択項目の位置・大きさを変更」を押し、新しい範囲を囲む。
- 一覧の「削除」はその項目だけが対象。別の色の項目は残る。
- 「元に戻す」「やり直す」も使用可能。
- 画面をスクロールしたい場合は「選択・スクロールへ戻る」。範囲指定中でも2本指拡大が可能。

### 表示確認・公開

編集中は位置を見失わないよう、追加した項目をすべて表示する。
「この下書きで表示を試す」を押すと、保存前でもオレンジ・赤・緑のON／OFFを試せる。
表示設定のボタンと、PDFのすぐ上の設定は連動する。「編集に戻る」で編集へ戻る。

「下書きを保存」だけでは全員に公開されない。
公開画面に反映したいときは、表示を確認してから「公開する」を押す。

## 今回の修正内容

- 色・用途ごとの専用追加ボタン。
- 操作を選ぶ→入力または範囲指定→保存・確認、の3段階を明記。
- オレンジなどの文字はドラッグに加え、タップ配置に対応。
- 緑は原文を隠す緑マーカーとして表示。緑ONで原文が見え、OFFで緑色に覆われる。
- 色別の一覧・件数・選択・個別削除。
- 操作中はPDFの上に次の操作と中止・編集メニュー・保存のボタンを表示。
- 公開前の下書きで表示切り替えを確認可能。
- 配置・更新前の入力がある場合は、保存時に見落とさないよう案内。入力も端末内に退避し、再読み込み後に復元可能。
- エラーは画面上部だけでなく編集欄とPDFの操作案内にも表示。

## 既存データ・機能への影響

保存形式・API・ID・画像基準の座標はv15から変更しない。
既存のPDF・追加文字・復習・メモは削除・移行しない。
v15の緑文字を隠す範囲（green-mask）は、同じ範囲のまま緑マーカーとして使える。見え方は、以前のOFF時の白塗りから緑塗りに変わる。
原本PDFは変更しない。既存の世界史プリントの表示・検索・切り替え・地図・年表は変更しない。
