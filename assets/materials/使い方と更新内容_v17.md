# 教材ライブラリ：古プリに合わせた表示・倍率 v17

GitHub最新版 7766579d16971bd23f48846331f6261f2327089a（v16適用済み）を基準に変更。
既存の古プリ「No016-018」の表示・倍率・指定範囲の操作を確認して教材画面に反映。

## 適用方法

1. v17のZIPを解凍せず `_update_inbox` に1個だけ置く。
2. `更新パックを適用.bat` を実行。
3. GitHub DesktopでCommit → Push。
4. 公開サイトを再読み込みして教材を開く。

CloudflareのWorkerはv15のままで使用できる。SQL・Worker・R2の更新は不要。
公開URLを維持するため pages/material.html は同じ名前で更新し、追加のJS・CSS・説明書・ZIPにはv17を付けている。

## 古プリに揃えた基本操作

- 最初はオレンジ・緑をOFF、全体表示、倍率100%。
- 上段は「オレンジ文字」「緑マーカー」「上部を隠す」。
- 続いて「全体／指定範囲」「＋ 範囲を追加」「範囲を削除」。
- 「上部を隠す」で見出しなどを閉じても、表示設定と下部操作は残る。「上部を表示」で戻せる。
- 下部は前・ページ選択・次と「− 100% ＋」。ボタンは25%刻み、25〜400%。
- スマホ・iPad相当の2本指操作で、指の中心を基準に拡大縮小。倍率は0.5%刻みに調整。
- PCでは拡大したPDFをドラッグで移動でき、ホイールでスクロールできる。
- 100%の基準幅は古プリと同じ計算（画面の余白を除いた幅、最大980px）。
- 最後のページで「次」は先頭へ、先頭で「前」は最後へ移動する。
- 復習・メモは倍率の隣の欄から開く。メモ件数はそのページにメモがあるときだけ表示。本文を隠さないよう操作パネルは必要時に開く。

オレンジの基本スイッチは、追加したオレンジ文字・赤文字と、登録した原文の赤文字を隠す範囲に連動する。
赤だけを別に切り替える場合は「その他の表示・教材操作」→「赤文字を個別に表示」。
緑はONで原文が見え、OFFで緑色に隠れる。追加した緑文字も同じスイッチに連動する。
原本PDF自体の文字を自動判定する機能は追加していない。原文を隠す場所は編集画面で登録する。

## 表示用の指定範囲

1. 「＋ 範囲を追加」を押す。
2. PDF上で左上から右下へ囲み、範囲名を入力する。
3. 「指定範囲」では、有効な範囲の中だけオレンジ・緑などの表示スイッチが働く。範囲外の答えは隠れたまま。
4. 「指定範囲の一覧」で個別の有効／無効・削除ができる。
5. 「全体」でページ全体の表示切り替えに戻る。

複数範囲の重なりにも対応。1ページ50個まで。範囲がない／全て無効の場合は全体と同じ表示になる。
「範囲を削除」は現在のページの表示用範囲だけが対象。追加文字・マーカー・復習・メモは残る。

表示用範囲は古プリと同様に端末側へ保存する。教材・ログインアカウント別のIndexedDBで管理するため、同じ端末・アカウントで再読み込みしても保持されるが、別端末へは同期しない。ブラウザのサイトデータを消すと失われる。

下部の「復習」→「範囲を囲む」は、復習・メモを登録するための別の操作。こちらの登録と履歴は従来通りサーバーに保存され、同じログインアカウントの端末間で同期する。

## 編集・既存データ

編集中は位置を確認できるよう全て表示し、表示スイッチ・表示用範囲は「表示を試す」で有効になる。
オレンジ・緑・赤の追加、選択・位置変更・削除、元に戻す／やり直す、下書きの保護、保存・公開を維持。
公開後も管理者が編集して保存・再公開できる。

保存形式・API・ID・画像基準の座標は変更しない。既存のPDF・追加項目・復習履歴・個人／共通メモはそのまま使用する。
認証・アカウントごとの権限検証・サーバー保存・再送も既存Worker v15を使用。
原本PDF・画像の追加／変更／再圧縮は行っていない。
既存の世界史プリント・OCR検索・地図・年表のファイルは変更していない。
