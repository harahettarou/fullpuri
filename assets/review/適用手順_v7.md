# 復習・メモ表示の調整 v7

基準：GitHub main `fc42e84e35a5e48410bcf18eab335a1bf8205ded`。復習・メモ機能v3導入済みサイト向けの差分です。

## 変更

- 通常のボタンは「復習 ○件」のみ。
- 今開いているNo.にメモがあるときだけ「復習 ○件・メモ ○件」を表示。同じNo.内の全ページのメモを数え、別No.のメモは含めません。
- メモの保存失敗・未送信・競合は、変更を失わないよう状態表示を残します。
- v4でズーム列に入れた復習ボタンを、以前の独立した右下表示へ戻しました。倍率・ページ送りの配置は元に戻ります。
- 復習ボタンの位置は下部操作欄の実際の高さを測り、その上へ配置します。画面回転や幅変更にも追従し、＋・−やページ送りに重ならないようにしています。
- v6の「No.85 ｜ ルネサンス」の表示修正も含みます。「ナンバー順：」や登録語句は復習管理の項目名に表示しません。

## 適用

v4・v5・v6を未適用でも、このv7だけを適用できます（v3導入済みが前提）。
1. ZIPを解凍せず、_update_inboxにこのv7だけを入れる。
2. 更新パックを適用.bat → GitHub DesktopでCommit → Push。
3. 公開後、PCではCtrl+F5、携帯・iPadは再読み込み。
Cloudflare・D1の更新は不要です。保存済みの復習・メモ・履歴・回数は変更しません。

## 確認

ローカルSQLite・仮想DOMで17件成功。メモがないNo.／同じNo.の別ページにメモあり／別No.だけメモあり／最後のメモを削除／No.切替時の表示を確認。復習ボタンがズーム列に入らず、下部操作欄の高さ変更時に位置指定が追従することも確認。既存の保存・同期・メモ・復習状態・範囲・黒文字等の試験も成功しました。

既存48閲覧HTMLは追加機能の参照先更新だけで、元の閲覧処理は保持しています。画像・OCR・地図・サーバーには変更ありません。実際のiPhone・iPad・PCでのv7の描画は未検証です。適用後に画面回転や倍率操作、復習ボタンの位置を確認してください。
