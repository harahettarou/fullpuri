# 共通メモ 実装・検証報告 v12

## 基準と変更内容
GitHub最新版 `5a438aabd1f1d81d5f0f9ae02a35d79ce4a54ae1` を取得して作成。
- 表示設定をタイトル直下に置いたv11の構成、青枠、復習・メモの整理を維持。
- 共通メモ・個人メモ・両方の表示切り替え。初期状態は共通。
- 新規メモの保存先の明示、既存メモの保存先を固定した編集。
- 全ログイン利用者の共通メモ閲覧・追加・編集。
- WorkerのADMIN_USER_IDSと認証済みセッションによる管理者判定。一般ユーザーの削除・復元をAPIでも拒否。
- 共通メモの変更履歴、作成・更新者、管理者向け削除済み表示・復元。
- 個人メモは既存の保存先を維持し、共通化しない。
- 共通・個人それぞれの未送信キュー、オフライン保持、競合解決、端末間の再同期。
- 新コアは既存のIndexedDBと個人メモのキーを使用。共通メモの未送信変更もログアウト・Google連携前に確認。
- メモの深いリンクに保存先を含め、同じ位置の個人・共通メモを取り違えない。従来の個人メモURLも維持。

## 保存・権限
GitHub Pagesの静的構成、既存のGoogle/GitHubログイン、Cloudflare Worker＋D1を使用。
shared_notesに現在の共通メモ、shared_note_operationsに重複送信防止の操作記録、shared_note_historyに各版の内容・操作・日時・実行者を保存。
D1トリガーで版番号確認・メモ更新・履歴追加を1回のINSERTとして実行。競合時には更新を中止。
識別ID・元画像座標は従来の方式を使用し、対象ごとの重複登録を防止。
削除は論理削除で本文と履歴を保持。復元時に本文と作成者を保持し、新しい版と履歴を追加。
権限を表すリクエストの自己申告値は使用しない。管理者IDは認証された学習IDとサーバー設定を照合。
未認証アクセス・不正な接続元・対象IDの改ざんを拒否。個人メモの所有者検証は従来どおり。
他利用者向けの作成者表示は識別ラベルとし、メールアドレスは共通メモの表示や履歴APIに含めない。

## 検証済み
実際のWorkerコードとSQLを使用したローカルSQLite、独立したブラウザDOM・IndexedDBクライアントによる自動テスト53件がすべて成功。
- 共通メモの初期設定、別利用者による閲覧・編集、個人メモとの分離。
- 管理者のみの削除・復元、偽の権限申告の拒否、権限取り消しの即時検証。
- 同時編集の競合、重複送信と履歴の正確さ、履歴のページ分割。
- 削除した本文と作成者の保持、一般ユーザーによる削除済み項目の再登録拒否。
- 再読み込み・オフライン保持・再送、アカウント切り替え時の個人メモの非表示、未送信時のログアウト拒否。
- 青枠・保存座標・対象への移動、共通と個人のメモの取り違え防止。
- 既存の復習履歴・回数・日付・重複防止、個人メモの保存・検索・競合、Google/GitHub連携の回帰確認。
- 既存画像・OCR・検索・色切替・ズーム・世紀別等の本文スクリプトを変更していないことを差分照合。

## 未検証・反映待ち
- 本番Cloudflareの管理者変数、SQL、Workerの反映はユーザー側の設定が必要。
- 公開サイトの共通メモについて、実際の別アカウント・PC・スマホ・iPad間での確認は設定後に実施する必要がある。
- 実ブラウザの描画検証は、この実行環境でブラウザを導入できず未実施。画面幅・ピンチ操作・Safariの実機検証は未実施。
- 既存の色切替・OCR検索・地図・年表等は変更していないが、v12反映後の実機操作までは未検証。
- 表示範囲の設定はこのブラウザに保存。メモ本文・履歴・権限の永続保存先はサーバー。

必要な外部設定はADMIN_USER_IDS、共通メモ用の追加SQL、Worker v12のみ。新規サービス契約やGoogleの秘密情報の再入力は不要。
