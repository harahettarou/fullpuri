# 共通・個人メモを両方表示 v14

GitHub最新版3954ccb388a937d5b4352618b98500a9de394311を基準に更新。

初期表示を「両方」に変更し、共通メモと自分の個人メモを同時に表示する。更新後、以前の表示設定に関係なく初回は「両方」になる。その後の手動での表示選択は保存する。新規メモの初期保存先は引き続き共通メモ。

削除の仕組みは変更しない。
- 共通メモから削除しても自動で個人メモにはならない。
- 個人側にも保存済みなら、その個人メモは残る。
- 共通にしか保存していない場合は通常の一覧から消える。ただし本文・履歴はサーバーに残り、管理者が復元できる。
- 共通メモを個人側にも残したい場合は、削除前に編集画面の保存先から個人メモにコピーできる。
- 個人メモから共通メモへの追加でも、元の個人メモは保持する。

適用：ZIPを解凍せず `_update_inbox` → 更新バッチ → Commit・Push → サイト再読み込み（PCはCtrl+F5）。Cloudflare・SQL・Workerの更新は不要。

JS5件とHTML50件の読み込み参照を更新。CSS・画像・OCR・サーバー・認証・保存先は変更なし。自動テスト62件成功。表示範囲・新規保存先・個人と共通の分離・削除対象・コピー・同期・履歴・認証の回帰確認を実施。実機表示は未確認。
