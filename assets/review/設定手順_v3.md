# メモ機能追加 v3：設定・適用手順

2026年10月16日（日本時間）。GitHubの最新版 `2418d0f5fd7627c556105d5be7617f57d9c6355a` を基準にした、復習機能v2導入済みサイト向けの差分です。

## 機能

- No.全体・ページ・色付き語句・選択した黒文字・手動指定範囲へ、1対象につき1つの文字入力メモ（最大6000文字）。
- 復習登録のない対象にもメモを作成可能。
- 語句タップ時の「メモを書く」、右下の「復習・メモ」メニューから利用。
- メモがある語句・範囲は小さな鉛筆アイコンで表示。表示設定から非表示にできる。余白のない箇所はアイコンを省略し、語句一覧やメモ一覧から操作。
- メモ一覧で本文・語句検索、種類・No.絞り込み、更新日・作成日・No.順、編集・削除・元位置の強調表示。
- 既存GitHubログインを共有し、同じアカウントのPC・スマホ・iPadへ同期。

## 1. D1へメモ用の保存領域を追加

Cloudflare → D1 → 既存の `fullpuri-review` → Console を開きます。
`server/migrations/0002_notes_v3.sql` をメモ帳で開き、全内容をコピーして実行してください。

既存の `entries`・`history` 等は変更しません。データベースを作り直さないでください。
SQL内のCASE式は、以前のConsoleエラーを避けるため括弧で囲んであります。

次の確認クエリで5行出ることを確認します。

```sql
SELECT type,name FROM sqlite_master
WHERE name IN ('notes','notes_owner','note_operations','note_guard','note_apply')
ORDER BY type,name;
```

もしまとめての実行がエラーになる場合は、最初の3つのCREATE（2テーブル・1索引）を実行し、各CREATE TRIGGERをBEGIN〜END;を含めて1つずつ実行してください。いずれもIF NOT EXISTSを使用しているため、作成済みのものを削除する必要はありません。

## 2. Workerを更新

Workers & Pages → `fullpuri-review` → Edit code。
`server/worker_v3.mjs` の全内容で、左側の `worker.js` を置き換え、Deployを押します。
設定済みのSITE_URL・GITHUB_CLIENT_ID・GITHUB_CLIENT_SECRET・DBはそのまま使います。秘密情報の再発行や新しいサービス契約は不要です。

https://fullpuri-review.niwatorikounotori.workers.dev/health を開いて確認します。

```json
{"ok":true,"version":3,"features":["review","notes"]}
```

v3 Workerには既存の復習APIも含みます。

## 3. 古プリ側を更新

1. `_update_inbox` をこのv3 ZIPだけにします。解凍不要です。
2. 既存の「更新パックを適用.bat」を実行します。
3. GitHub Desktop → Commit to main → Push origin。
4. GitHub Pages更新後、PCはCtrl+F5、iPad・スマホは再読み込みします。開きっぱなしの旧画面は閉じて開き直してください。
5. プリント右下のメニューに「このページにメモ」「範囲を囲んでメモ」等が出れば反映されています。

このZIPはv3差分です。v2の上から適用し、v1・v2を再適用しないでください。

## 4. 本番で確認

1. プリントの語句→「メモを書く」→入力→保存。
2. 右下のメニューで「メモ：サーバー保存済み」を確認。
3. メモ一覧に反映され、再読込でも残ることを確認。
4. iPad等で同じGitHubアカウントにログインし、同じ内容が見えることを確認。
5. 別端末で追記し、PCで「再同期」を押して更新を確認。
6. メモを削除しても、既存の要復習・完了状態・回数が変わらないことを確認。
7. 黒文字、手動範囲、No.・ページのメモ、アイコン非表示、ズーム、元位置リンクを確認。

## 保存失敗・競合

「メモを保存」を押した内容は端末のIndexedDBに未送信操作として保存してからサーバーへ送信します。通信失敗時はこの端末に保持して再送します。サーバー保存が完了する前にブラウザのデータを消すと、未送信の内容は失われます。
未送信メモがある場合はログアウトを止めます。

編集中の本文は自動保存しません。「メモを保存」を押してください。未保存のまま閉じる・ページを移る操作には確認を表示します（OSによる強制終了等は対象外）。

別端末で同じメモを編集した場合、無言で上書きせず競合として保留します。メモ一覧で「サーバーのメモを確認」を押し、入力欄に内容をまとめて「入力内容を保存」、または「サーバー側を採用」を選びます。
通常の同期は約30秒ごと、画面への復帰時、オンライン復帰時です。「再同期」ですぐ取得できます。

削除はメモ一覧から除外する方式です。競合防止用の版番号・削除情報と操作記録はD1内に保持します。
