# 要復習チェック・復習管理機能 v2：適用手順

2026年10月16日（日本時間）。v1は適用せず、このv2だけを使ってください。v1と同じ機能一式を含みます。

## 設定済みの内容

- 古プリ側のAPI接続先：https://fullpuri-review.niwatorikounotori.workers.dev
- SITE_URL：https://harahettarou.github.io/fullpuri/
- GitHub OAuth Appの公開Client IDとD1の識別番号をサーバー設定ファイルへ反映済み。
- Cloudflare上でDBバインド、環境変数、Client Secretを利用者が設定済み。
- D1の6テーブル・2索引・2トリガーの存在を、利用者から提示された実行結果で確認。
- Workerの /health が {"ok":true,"version":1} を返す画面を確認。

Client SecretはこのZIPに含めていません。既存のCloudflareの秘密設定を使います。

## サイトへ適用

1. リポジトリ内の `_update_inbox` に、このv2 ZIPを1個だけ置きます。古いZIPが残っていれば別の場所へ移してください。
2. ZIPは解凍せず、既存の「更新パックを適用.bat」を実行します。
3. 成功表示を確認し、GitHub Desktopで変更内容を確認して Commit to main → Push origin を実行します。
4. GitHub Pagesの公開完了後、https://harahettarou.github.io/fullpuri/pages/review.html を開きます。
5. 「GitHubでログイン」を押し、ログインを開始した同じタブで戻ります。

既存HTMLの名前はリンクを維持するため変更しません。追加プログラムの参照名も維持し、配布ZIPと今回の説明書・検証結果にv2を付けています。

## 必ず続ける動作確認

- PCでプリントを開き、色付き語句を要復習へ登録。「サーバー保存済み」になることを確認。
- 復習管理に反映され、再読込後も残ることを確認。
- 復習完了で回数1・日付が入り、再登録後も過去の回数・履歴が残ることを確認。
- iPad・スマホで同じGitHubアカウントにログインし、同じ記録を取得できることを確認。
- 別アカウントではその記録が表示・編集できないことを確認。
- 黒文字の選択、手動範囲、ページ・No.単位、直接／タップ／非表示、25〜400%とピンチを確認。
- 既存の色切替、上部を隠す、指定範囲、OCR検索、各一覧、地図・年表を確認。

これらの本番ログイン・保存・同期・実機確認は、ZIP作成時点では未実施です。
同期待ちは最大約30秒です。復帰時・再同期ボタンでも更新します。

## サーバーの保守

- 作成済みD1を削除・再作成しないでください。
- SQL内のCASE式は括弧で囲み、今回D1 Consoleで受理された形式へ修正しました。
- dashboardで作成済みのため、SQLの再実行は不要です。
- 期限切れログイン情報の定期削除は、Workerの設定でCron `0 3 * * *` を追加すると有効になります（UTC 03:00、日本時間12:00）。未設定でも期限の検証は常に行います。
- 本番バックアップには個人の学習記録を含むので、公開リポジトリに入れないでください。
