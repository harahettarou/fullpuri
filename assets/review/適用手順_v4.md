# 復習・メモボタンの重なり修正 v4

基準：GitHub main `d55cda7d6947d47e39fc05cad91ee0c8170be330`（メモ機能v3導入済み）。

## 変更

画面右下に固定していた復習・メモボタンを、下部のズーム操作と同じ列の通常配置に変更しました。幅が足りない場合は折り返し、ページ送り・倍率・＋・−に重ならないようにします。PC・スマホ・iPadで同じ配置方式を使います。

## 適用

1. このv4 ZIPだけを `_update_inbox` に入れる（解凍不要）。
2. 「更新パックを適用.bat」を実行。
3. GitHub Desktopで Commit to main → Push origin。
4. サイト更新後、PCではCtrl+F5、スマホ・iPadではページを再読み込み。反映されなければ開き直す。

Cloudflare・D1・ログインの再設定は不要です。復習記録・メモ・画像・OCRデータの変更はありません。

## 確認

最新版の48閲覧HTMLを確認し、全ページに同じズーム操作領域が存在することを確認しました。HTMLはCSS・JS参照のバージョン更新のみ。閲覧プログラムはボタンの挿入先1か所だけを変更しています。

ローカルSQLiteと仮想DOMで16件成功。保存・同期・復習状態・メモ・範囲・黒文字・元位置に加え、復習ボタンがズーム操作領域に1つだけ置かれることを確認しました。
実際のiPhone・iPad・PCでの描画は未検証です。適用後、縦向き・横向きでページ送りと＋・−が押せること、復習ボタンが必要に応じて折り返されることを確認してください。
