# Googleログイン・アカウント連携 v8

2026年10月16日。既存の復習・メモ機能を導入済みのサイト向けです。
GitHub最新版 `a789ac62bd8a00875b7a381336d747b634398954` を基準にしています。

## 最初に

以前からGitHubで利用していた人は、まずGitHubでログインし、その状態で「Googleアカウントを連携」を押してください。以後はGoogleで同じ記録を利用できます。

最初にGoogle単独でログインすると、別の学習アカウントを作成します。別アカウントとして作成した記録の自動統合は行いません。メールアドレス一致による自動連携もしません。

設定・動作確認が終わるまで、GitHubログインは回復用として残します。GitHub側の設定・秘密情報を削除しないでください。

## 1. Googleにログイン用アプリを作成

https://console.cloud.google.com/ を開きます。

1. プロジェクトを新規作成。名前の例：`fullpuri-review`。
2. 「Google Auth Platform」（または「OAuth同意画面」）を開く。
3. アプリ名は「古プリ 復習管理」。サポートメール・連絡先には自分のメールを選択。
4. 対象は「外部」。まずテスト用として自分のGoogleアカウントをテストユーザーに追加する。
5. 「クライアント」からOAuthクライアントを作成。種類は「ウェブアプリケーション」。
6. 承認済みのリダイレクトURIへ、次を正確に登録する。

```text
https://fullpuri-review.niwatorikounotori.workers.dev/auth/google/callback
```

今回はサーバーへの転送で認証するため、承認済みJavaScript生成元は使いません。
求める権限は `openid email` のみ。Gmail・Drive・Calendarのデータを読み取る権限は求めません。
一般公開する場合は、Googleの対象・公開設定と、表示された必要事項を確認してください。

## 2. Cloudflareへ認証設定を追加

Workers & Pages → `fullpuri-review` → Settings → Variables and Secrets。

| 種類 | 名前 | 値 |
|---|---|---|
| Text | GOOGLE_CLIENT_ID | Googleが発行したClient ID |
| Secret | GOOGLE_CLIENT_SECRET | Googleが発行したClient Secret |

Client Secretはチャット・HTML・JS・ZIP・公開GitHubに貼り付けません。CloudflareのSecret欄へ直接入力します。
既存のSITE_URL・GITHUB_CLIENT_ID・GITHUB_CLIENT_SECRET・DBは保持します。

## 3. D1へ連携用のテーブルを追加

D1 → `fullpuri-review` → Consoleで、`server/migrations/0003_google_v8.sql` の全文を実行します。
既存の復習・メモのテーブルは変更しません。

確認クエリで5行出ることを確認します。

```sql
SELECT type,name FROM sqlite_master
WHERE name IN ('google_identities','google_states','google_tickets','google_states_expiry','google_tickets_expiry')
ORDER BY type,name;
```

## 4. Workerを更新

Workers & Pages → `fullpuri-review` → Edit code。
`server/worker_v8.mjs` の全内容で `worker.js` を置き換え、Deployします。
次を開きます。

https://fullpuri-review.niwatorikounotori.workers.dev/health

```json
{"ok":true,"version":8,"features":["review","notes","google-login","account-linking"],"google_configured":true}
```

google_configuredがfalseの場合は、GOOGLE_CLIENT_IDとGOOGLE_CLIENT_SECRETの両方が設定済みか確認します。
この応答だけではGoogleのClient ID・Secretの正しさや、実ログインの成功までは保証しません。

## 5. 古プリへ適用

v8 ZIPだけを `_update_inbox` に置き、更新パックを適用.bat → GitHub DesktopでCommit → Push。
公開後に再読み込みしてください。PCならCtrl+F5。開きっぱなしの旧画面は閉じて開き直します。
v5〜v7の項目名とボタン配置の変更も含みます。

## 6. 既存記録をGoogleへつなぐ

1. 復習管理を開く。以前のGitHubアカウントでログイン済みであることを確認。
2. 復習・メモの保存を済ませる。未送信がある場合は連携を止めます。
3. 「Googleアカウントを連携」を押す。
4. Googleの画面で自分のGoogleアカウントを選ぶ。同じタブで最後まで進む。
5. 古プリへ戻り「Google連携済み」と表示されること、既存の復習・回数・メモが残っていることを確認。
6. ログアウトし、「Googleでログイン」。同じ記録が表示されることを確認。
7. iPad・スマホでも同じGoogleアカウントでログインし、保存・完了・メモ編集を相互に確認。

Googleからアクセス拒否が出る場合は、テストユーザーにそのアカウントを追加したか、Client種別とリダイレクトURIが一致するか確認します。
別の学習アカウントで使っているGoogleアカウントは連携できません。内容を上書き・自動統合せず、エラーで止めます。

## 保守

D1の作り直しは不要です。旧セッション・復習・メモ・履歴・利用者IDを保持します。
WorkersのCronを設定済みなら、期限切れのGoogle認証中データも同じ定期処理で削除します。Cron未設定でも有効期限は各認証処理で検証します。

wrangler_v8.jsoncでCLI公開する場合は、ダッシュボードで設定した公開Client IDをvarsにも追加してから利用してください。今回の手順はEdit codeでの公開を前提にしています。
