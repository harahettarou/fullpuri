# v15 テスト

Node.js 24以上。テスト用にhappy-domとfake-indexeddbをインストールする。既存のtests/package.jsonを利用できる。
リポジトリのルートで実行:

```sh
npm install --prefix assets/review/tests
node --experimental-vm-modules --test assets/review/tests/client_v15.test.mjs assets/review/tests/api_v15.test.mjs assets/review/tests/google_v15.test.mjs assets/review/tests/materials_v15.test.mjs assets/review/tests/materials_client_v15.test.mjs
```

81件。SQLiteはNodeのnode:sqliteを使用。Cloudflareの認証秘密情報は不要で、実サービスへ書き込まない。materials_clientのPDF描画だけは軽い代替を使用し、実エンジンの描画は以下のブラウザ検証で行う。

## ブラウザ検証

PlaywrightとChromiumが必要。環境へインストール後、`node assets/review/tests/browser_e2e_v15.mjs` で実行する。
既存のPlaywrightを使う場合はKOPURI_BROWSER_MODULESにそのpackage.jsonがあるディレクトリーを指定できる。KOPURI_CHROMIUM_PATHでブラウザ実行ファイルを指定可能。
KOPURI_BROWSER_OUTPUTで出力先を指定でき、省略時はtests/output_v15。必要ならKOPURI_QA_FONTに日本語フォントのファイルを指定する（フォントのない検証環境向け）。
実サイトのURLへのアクセスをすべてテスト内で置換し、ローカルの実装・実PDF・テスト専用ユーザー・SQLite・R2代替で検証する。サイトへの公開や本番APIへの書き込みは行わない。
PDFのFile送信はPlaywrightの経路上でバイト列を読み取れるようにテスト用アダプターを使用する。本番のCloudflare R2への転送と同じとはみなさない。

ブラウザ検証: PC・スマホ・iPad相当の描画、表示切り替え、倍率、復習、メモ、PC編集・保存・公開・PDF選択、タッチ範囲指定・ピンチを確認する。iPhone/iPad実機やSafariの検証は別に必要。
