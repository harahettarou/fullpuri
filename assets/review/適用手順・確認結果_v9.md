# メモ位置を見やすくする更新 v9

最新版の origin/main（3b3c368890423be70ac68df958ff96e472347f0c）を基準に作成。

## 変更
- メモを付けた語句・範囲を青い点線枠で表示。余白がなくアイコンを置けない場所も表示。
- 保存した元画像の座標を使用。文字の上を塗らず、枠はタップ・スクロール操作を遮らない。
- メモの鉛筆アイコンを青色に統一。
- 復習・メモの設定内に「このページのメモ（件数）」を追加。「位置を表示」で青い太枠とスクロールで示し、「メモを見る・編集」から開ける。
- No.全体・ページ全体のメモはページ外周を青い点線枠で表示。No.全体メモはそのNo.の各ページに表示。
- 設定の「メモの位置・アイコンを表示」で青枠とアイコンを非表示にできる。「チェックUI非表示」も維持。
- メモ一覧から戻った際の該当箇所の強調を青色に変更。

## 適用
1. ZIPを解凍せず `_update_inbox` に1つだけ入れる。
2. `更新パックを適用.bat` を実行。
3. GitHub DesktopでCommit → Push。
4. 公開後、PCはCtrl+F5、スマホは再読み込み。

Cloudflareのコード・変数・D1設定の変更は不要。既存メモ・認証・同期・履歴・原本画像はそのまま使用。

## 確認結果
- 実際のAPIコードとSQLite、ブラウザDOMを使う自動テスト39件すべて成功。
- 余白がない場合の青枠表示、拡大時の相対座標保持、ON/OFF、削除の即時反映を確認。
- No.全体／ページ／語句／範囲の対象分離と一覧、元座標への移動と編集を確認。
- 従来の復習登録・履歴・重複防止、メモ同期・競合、アカウント分離、Google連携の回帰テスト成功。
- 48件のHTMLは最新版の表示スクリプト・CSS参照のみ変更。画像やOCR座標・検索・色切替・既存の表示処理は変更なし。
- 実ブラウザによる画面描画検証は実行環境にブラウザがなく未検証。スマホ/iPad/PC実機、公開サイトでのv9の見た目とピンチ操作も未検証。
- 黒文字メモは従来どおりOCR行の範囲を保存しているため、青枠も行単位。文字の一部分の精密な位置が必要なら「範囲を囲んでメモ」を使用。
