# 編集画面の拡大・移動 v21

GitHub main 31953a096e48988e8dca2d768d10c6720c648d8f（v20適用済み）を基準にしています。

## 適用

ZIPを解凍せず `_update_inbox` に1個だけ入れ、`更新パックを適用.bat` → GitHub DesktopのCommit → Pushで適用します。
Workerの差し替え・SQL実行・外部サービス設定の変更は不要です。公開サイトを再読み込みしてください。

## 操作

古プリの修正画面で、2本指を開く／閉じると指の間を中心に拡大・縮小します。そのまま2本指を同じ方向へ動かすと、拡大率を保って紙面を移動できます。
「画面を移動」を選ぶと1本指のドラッグでも紙面を移動できます。PCではマウスドラッグで移動できます。範囲追加へ戻るときは「表示・操作」→「囲んで追加」を選んでください。
「選択・移動」で項目のない余白をドラッグした場合も紙面を移動します。項目をドラッグした場合は従来通りその項目の編集です。
＋／−ボタンは画面の中央を基準に拡大・縮小します。「画面に合わせる」で全体表示へ戻れます。
紙面の端では、画像の外へ移動し続けないようスクロール可能範囲で止まります。

## 修正内容

ピンチ開始時の元画像上の位置を保持し、拡大と指の移動を同時に反映します。指を1本ずつ離す途中に範囲が誤登録されないようにしています。紙面の移動操作では範囲の追加・削除・変更を行いません。
原本画像・PDF・保存済みの復習・メモ・編集データに変更はありません。教材ライブラリの編集画面は今回変更していません。

## 検証

ChromiumでPC・スマホ・iPad相当の画面幅を確認しました。スマホとiPad相当では実際のタッチイベントでピンチ拡大、2本指の平行移動、1本指の紙面移動、移動時に編集項目が増減しないことを確認しました。
既存の範囲追加・移動・サイズ変更・ダブルクリック／ダブルタップ削除、番号対応、下書き保存・公開、未登録対応の再読み込み復元、追加マーカーの復習登録・再読み込み後の保持も確認できています。検証結果JSONを同梱します。
テスト用セッション・SQLiteを使い、本番データは操作していません。実機のiPhone/iPad/AndroidとSafari、本番適用後の動作、Windowsの更新BAT実行は未検証です。
