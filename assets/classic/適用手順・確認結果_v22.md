# 緑マーカーの追加・画面移動の切り替え v22

GitHub main 1fe5552（v21適用済み）を基準にしています。

## 適用

ZIPを解凍せず `_update_inbox` に1個だけ入れ、`更新パックを適用.bat` → GitHub DesktopのCommit → Pushで適用します。
Cloudflare Worker・SQL・外部サービスの設定変更は不要です。適用後はサイトを再読み込みしてください。

## 修正と操作

- 「緑マーカー」「赤文字」「番号対応」を選ぶと「囲んで追加」に切り替えます。前の画面移動・項目移動モードを引き継ぎません。
- 「囲んで追加」を修正画面の上部へ移しました。押すと既存項目の選択を解除し、新しい範囲を囲めます。選択中の項目の角から囲み始めても、その項目を拡大・縮小しません。
- 「画面を移動」を押すと「移動を終了」に変わります。もう一度押すと直前の「囲んで追加」または「選択・移動」に戻ります。
- 既存マーカーを変更するときは紙面または一覧で選択します。2本指の拡大・紙面移動は継続使用できます。

原本画像・PDFや保存済みの復習・メモ・編集内容は変更していません。教材ライブラリの編集画面は今回変更していません。

## 変更ファイル

通常No.ページ38ファイルの参照先、assets/review/viewer_v22.js、assets/classic/editor_v22.js・correction_v22.js、ブラウザ検証用テスト、検証結果JSON、本手順。CSS・保存モデル・サーバーは既存版を使用します。

## 検証環境

ChromiumのPC・スマホ・iPad相当の画面幅とテスト用セッション・SQLiteで確認しました。スマホ・iPad相当のタッチ操作で、画面移動の開始と終了、追加・選択それぞれの操作への復帰、移動中から緑マーカーへの切り替え後の範囲追加、既存マーカーを選択した後でも新しい範囲を追加できて元の位置・大きさが変わらないことを確認しました。
従来のピンチ拡大・2本指と1本指での紙面移動、赤・緑の編集、番号対応、保存・公開、再読み込み復元、追加マーカーの復習登録・保存も確認しました。結果JSONを同梱しています。
本番データは操作していません。実機Safari、Windowsの更新BAT、本番適用後は未検証です。
