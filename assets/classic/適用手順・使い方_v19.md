# 古プリの編集ボタン縮小・修正モード v19

基準：GitHub main 03070f0dba74968dca3e04b626b55d97d2c4cb74（v18適用済み）。

## 適用方法

1. 更新ZIPを解凍せず `_update_inbox` に1個だけ入れ、`更新パックを適用.bat` を実行します。
2. `assets/review/server/worker_v19.mjs` の全文を、Cloudflare → Workers & Pages → fullpuri-review → Edit code に貼り替え、Deployします。
3. https://fullpuri-review.niwatorikounotori.workers.dev/health で version:19 と classic-correction-mode を確認します。
4. GitHub DesktopでCommit → Pushし、公開サイトを再読み込みします。

今回はSQLの実行は不要です。既存のDB・R2・認証・管理者設定をそのまま使います。
ZIPの適用だけではWorkerは更新されません。v18で作った classic_edits / classic_edit_operations / classic_edit_history と既存トリガーを使います。

## 変更内容

通常画面の「古プリを編集」をページ名と同じ行の小さなボタンにしました。PCで高さ24px、スマホで22pxです。編集ボタンのための行は増えません。
管理者が押すと修正専用画面を開きます。細かな操作は「表示・操作」にまとめています。

- 赤文字：左ドラッグで隠す範囲、右ドラッグで残す範囲を作ります。スマホでは種別を選んでから囲みます。既存の赤文字隠し・残す範囲も選んで修正できます。
- 緑マーカー：囲んで追加。既存マーカーも選んで移動、四隅のサイズ変更、色の変更ができます。
- 番号対応：本文の番号部分→解答欄の順で囲み、文字とサイズを指定して登録します。同じ単元内の別ページの解答欄も指定できます。既存の対応も選び、本文・解答を囲み直したり、文字を変更したりできます。
- 「選択・移動」で既存の範囲を選択し、ドラッグで移動できます。X/Y/幅/高さの数値指定も可能です。
- ダブルクリック／ダブルタップで範囲を削除できます。元に戻す／やり直すも使えます。
- 「表示・操作」で倍率、全体に合わせる、プレビュー、ページを切り替えます。ピンチ、カーソル位置でのホイール拡大、Spaceの一時プレビューも使えます。
- 「下書きを保存」では他の人の画面に反映されません。確認後「公開する」を押します。
- 以前の追加文字・白い覆い・履歴などは「その他の文字・履歴」から操作できます。

修正モードZIPの紙面操作を基にしています。ローカルPDFの置き換えやディスク自動保存機能は移植していません。サイトのアカウント認証と下書き保存・公開を使います。
画像に焼き込まれた文字自体を打ち直す機能ではなく、表示用の範囲・番号対応・追加文字を編集します。
通常No.ページの編集です。世紀別の切り出し・総合年表などを再生成する処理は含みません。

## 保存・安全性

v18の保存データもそのまま読めます。追加した範囲、緑の色、番号と解答欄の対応は既存D1のJSONへ保存します。管理者権限はサーバーで確認し、版番号と操作IDによる競合検出・再送・履歴保持を継続します。
公開版の単元内取得は公開済みデータだけを返し、下書きや編集者IDを返しません。
未登録の番号対応は端末のIndexedDBへ退避し、再読み込み後に復元できます。登録してからサーバーへ保存してください。
原本の画像・PDF・PAGESデータは加工していません。復習・メモの保存済み座標と履歴も変更しません。

## 確認結果

自動テスト105件成功。認証、ユーザー分離、復習履歴、メモ、教材、旧編集データ、保存・公開・競合の回帰テストを含みます。正規412ページの初期データも新Workerで検証しました。
ChromiumでPC 1440px・スマホ390px・iPad相当810pxを検証。編集ボタンによるヘッダーの追加高さは全て0px。赤の隠す／残す範囲、緑の編集・色・サイズ変更・直接移動、ダブルクリック／ダブルタップ削除、別ページにまたがる番号と解答欄、保存・公開・別ユーザーへの反映を確認しました。
未登録対応の再読み込み復元、既存番号の文字変更・囲み直し、Spaceプレビューとホイールズームも確認しました。
テストはローカルのテスト用セッション・SQLiteを使っています。本番データは操作していません。
実機のiPhone/iPad/Android、Safari、本番Worker更新後とZIP適用後の動作は未検証です。
