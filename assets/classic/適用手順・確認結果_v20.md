# 追加マーカーを復習に登録する修正 v20

GitHub main 93ecfd744a909e0c7117454765fe19efa410ab9a（v19適用済み）を基準にしています。

## 適用

ZIPを解凍せず `_update_inbox` に1個だけ入れ、`更新パックを適用.bat` を実行し、GitHub DesktopでCommit → Pushしてください。
今回はWorkerの貼り替え、SQLの実行、外部サービス設定の変更は不要です。Worker v19を継続使用します。
公開サイトを再読み込みしてから、古プリの編集を終了した通常の閲覧画面で登録してください。全員に使ってもらう範囲は従来通り「公開する」が必要です。

## 修正

古プリに追加・保存した緑マーカー、赤文字を隠す範囲、修正モードの追加した赤の範囲を復習チェックの対象に含めました。移動した既存の緑マーカーも新しい位置で登録できます。
文字追加と番号対応の登録は継続使用します。黒文字と白く覆うだけの範囲には自動でチェックを追加しません。
編集終了時にタップの無効状態が残る場合も修正しました。

既存の保存データから対象を作るため、マーカーを作り直す必要はありません。チェックのタップ表示・直接表示・語句一覧から登録できます。小さい画面や余白のない箇所では直接ボタンを省略し、タップと語句一覧を使えます。
元画像の座標で従来の復習保存APIに登録します。既存の復習回数・履歴・メモの記録や原本画像・PDFには変更を加えていません。

## 検証

新規の自動テスト2件成功。過去の形式で保存された範囲の取り出し、対象の種類と座標のサーバー検証、重複除外、文字列の変更後も識別情報を保つことを確認しました。
実画像とテスト用Worker・SQLiteを使ったChromiumのブラウザ検証で、PC・スマホ・iPad相当の表示と既存の修正操作・保存・公開を確認。一般ユーザーが追加した緑マーカーをタップして要復習へ登録し、サーバー保存・再読み込み後の保持を確認しました。
実機のSafari、本番への適用後、Windowsの更新BAT実行は未検証です。本番データは変更していません。
