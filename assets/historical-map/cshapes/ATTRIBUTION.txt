Changes made for this website:
- Original features divided into four time buckets for on-demand loading.
- Geometry simplified and coordinate precision reduced for web display.
- Country and territory names translated into Japanese.
- A display color index generated from shared-border adjacency.
- Unused original attributes removed from the web derivative.
